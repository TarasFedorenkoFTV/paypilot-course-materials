# US-01 — Currency conversion quote in chat

| Field | Value |
|---|---|
| Story ID | US-01 |
| Epic | PayPilot self-service |
| Author | Product (Verta Payments) |
| Status | Approved for build |
| Version | 1.0 |

## Story
**As a** Verta customer,
**I want** to ask PayPilot what a currency conversion will cost me,
**so that** I can decide whether to convert now or wait.

## Description
Customers routinely ask support what they will actually receive when converting
between currencies. Today they are redirected to the tariff page and often
misread it. PayPilot should answer in the chat, using the customer's own tier
and remaining allowance.

## Acceptance criteria
1. The agent responds to a conversion question with the applicable rate and the
   resulting amount.
2. The response must be helpful and easy to understand for a non-financial
   customer.
3. The agent should respond quickly.
4. The agent must not mislead the customer about costs.
5. Where the customer's free monthly allowance applies, the response reflects it.
6. The agent handles recent conversions correctly.
7. The response is consistent with the tariff schedule.

## Out of scope
- Executing the conversion (read-only quote for now).
- Corporate accounts.

## Notes
- Limits and spreads are per tier, as agreed with Payments.
- Escalate to a human when the customer disputes a quoted figure.
